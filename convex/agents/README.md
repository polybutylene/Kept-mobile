# Kept — Automated Agents

Automated agents for marketing, SEO, reel generation, and customer support.

## Agents

| Agent | File | Purpose |
|-------|------|---------|
| Social Content | `socialContentAgent.ts` / `socialPublisher.ts` | Weekly social media content generation & scheduled publishing |
| SEO/AEO Answers | `seoAnswerAgent.ts` / `seoAnswerHelpers.ts` | AI-optimized answer page generation from keyword queue |
| Reel Pipeline | `reelAgent.ts` | Multi-stage video script, voiceover, and visual generation |
| Customer Support | `supportAgent.ts` / `supportKBLoader.ts` | RAG-based support chatbot with escalation |
| Tests | `testAgents.ts` | Manual test triggers for all agents |
